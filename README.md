# Rubik's Cube Solver

This is a simple Rubik’s Cube Solver implemented in JavaScript. It simulates basic cube logic, random scrambling, and solving steps.

---

## 🚀 Features
- Object-oriented cube structure
- Manual rotation logging (U, D, L, R, F, B)
- Random cube generation (scramble)
- Step-by-step solving simulation
- Clear cube state display at each step

---

## 📂 Files in This Project
- `index.html` – Main HTML structure
- `style.css` – Styling for layout
- `cube.js` – Cube class and logic
- `script.js` – Scrambling, solving, and rendering
- `README.md` – (This file) Overview & instructions

---

## ▶️ How to Run
1. Download all files
2. Open `index.html` in your browser
3. The page will show scrambling, solving steps, and cube state
